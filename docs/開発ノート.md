# パスワード生成＆マネージャー

パスワードを忘れたり使い回したりすることを防ぐためのアプリです。現在は、画面構成を確認するための静的なデザインプレビューです。

## 画面の見方

- **パスワードを作成**：生成結果、文字数、文字種、生成ボタンの配置を確認できます。
- **パスワード一覧**：検索、新規追加、登録一覧の空状態の配置を確認できます。
- パソコンの画面幅に対応しています。

## 開き方

`index.html` と `style.css` を同じフォルダに置き、`index.html` をブラウザで開いてください。インストールやサーバーは不要です。

## 現在の範囲と注意

これは外観のみの試作です。ボタンや入力欄は操作できません。パスワードの生成・コピー・登録・検索・編集・削除・保存は実装していません。**実際のパスワードや個人情報を入力しないでください。**
